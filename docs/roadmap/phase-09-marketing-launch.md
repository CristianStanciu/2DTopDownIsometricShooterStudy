# Phase 9 — Marketing & Launch

**Goal:** arrive at launch with an audience: visibility plan from M2, wishlist campaign, demo/festival presence, press coverage, and a rehearsed launch week.
**Depends on:** P8 store page (copy/assets) · playable content (M2+).
**Effort:** ~8–12 person-weeks across M2–M5 (partly parallel) · **Gate:** M5 launch day

## Exit criteria
- [ ] ≥10,000 wishlists at launch (or documented alternative plan accepted) · Steam page live ≥3 months pre-launch
- [ ] Launch checklist executed: build in depot, discount live, press keys sent, trailer published, day-1 ops staffed
- [ ] Post-launch metrics instruments confirmed receiving data (P6.E4.T4) before announcement

---

## Epic P9.E1 — Brand & web presence (~2 pw)

- [ ] **P9.E1.T1** — Identity package: final name (P0.E8.T3), logo, color/type system, key art direction; consistency across store/social/trailer
- [ ] **P9.E1.T2** — Landing page + official site: screenshots, trailer embed, wishlist button (Steam link), mailing list opt-in, press kit download (logos, gifs, fact sheet)
- [ ] **P9.E1.T3** — Socials: X/Bluesky + Discord (structure: announcements/bug-feedback/playtests/rules/mods), YouTube/TikTok channels; handle availability confirmed in P0.E8.T3
- [ ] **P9.E1.T4** — Press kit contents: fact sheet (genre, platforms, price, release window, studio bio), 5 gif loops, screenshots, logos, contact + review-key instructions

## Epic P9.E2 — Content marketing campaign (rolling from M2, ~3 pw)

- [ ] **P9.E2.T1** — Devlog cadence: 2 posts/month (design deep-dives from this roadmap — combat feel, enemy readability, juice) on site + social cuts; asset templates for consistency
- [ ] **P9.E2.T2** — Trailer milestones: teaser (M2, announcement), gameplay trailer (M3), launch trailer (M4); each with captions, 16:9 + vertical cut for socials
- [ ] **P9.E2.T3** — GIF/clip library maintained continuously from playtest captures (pillar moments: dash-kill chains, boss reveals)
- [ ] **P9.E2.T4** — Community challenges: screenshot contests, naming events (post-1.0 content) — engagement loops with moderation coverage
- [ ] **P9.E2.T5** — Paid promotion tests (small): $200–500 experiments on demo launch trailer; CTR/wishlist-CAC recorded; scale only if CAC acceptable — *only after P8.E3.T4 remediation done*

## Epic P9.E3 — Press, creators & festivals (~2 pw)

- [ ] **P9.E3.T1** — Target list (~50): top-down/shmup/cyberpunk creators, indie outlets, streamers mid-tier (1k–100k); CRM sheet with status
- [ ] **P9.E3.T2** — Steam Next Fest plan (recommend M4 window): demo build (P8.E2.T6) + festival-exclusive build update + streaming presence; pre-fest announcement posts; daily bug triage during fest (P7 on call)
- [ ] **P9.E3.T3** — Key distribution: press/creator keys via Steamworks, embargo guidance, follow-up thank-you; conversion tracked (creator links/referral)
- [ ] **P9.E3.T4** — Award/selection submissions (indie showcases, IGF-adjacent where eligible) — calendar with deadlines in `docs/business/calendar.md`

## Epic P9.E4 — Wishlist & audience growth (~2 pw)

- [ ] **P9.E4.T1** — Funnel instrumentation: page views → wishlists (Steamworks), site click-through, mailing list growth; weekly review cadence from M3
- [ ] **P9.E4.T2** — Milestone campaigns: trailer drop, demo drop, release-date announcement, launch — each with coordinated socials/press/newsletter
- [ ] **P9.E4.T3** — Wishlist target checkpoints: 5k by M4 start, 10k by launch; below-target contingency: extra streamer push, bundle participation, extended demo window
- [ ] **P9.E4.T4** — Newsletter: Mailchimp/locomotive-lite, biweekly devlogs, launch code giveaway incentive; consent + GDPR checkbox (P8.E3.T2)

## Epic P9.E5 — Launch execution (M4–M5, ~2 pw)

- [ ] **P9.E5.T1** — Launch plan doc: T-minus schedule (build freeze, depot upload, assets final, press embargo lift, trailer go-live, discount verify, social wave), owners + rollback plan
- [ ] **P9.E5.T2** — Day-1 readiness: staging rehearsal upload of RC (P7.E6.T4), regional pricing verified, store text final proofread, achievements list final, age gate verified
- [ ] **P9.E5.T3** — Launch discount + pricing strategy final (P8.E4.T3): 10% typical; bundle consideration; no deeper discount for ≥30 days post-launch
- [ ] **P9.E5.T4** — Launch-day runbook: monitoring (crash telemetry, reviews, Discord), response templates, bug intake via P7.E6.T1, hotfix SLA per P10.E1
- [ ] **P9.E5.T5** — First-week review: sales/wishlist conversion/refund rate vs targets, review score baseline, top complaints → P10 backlog; postmortem written

**Phase 9 DoD:** exit criteria checked; launch retrospective archived.
